MHServerEmu 1.0.3 Patch Notes

General

  • Retargeted the server to .NET 10. It now requires the .NET 10 runtime to run.
  • Updated libraries:
    • Dapper to 2.1.89
    • System.Data.SQLite to 1.0.119
  • When AutoUnlockTeamUps config setting is enabled, team-ups will now also be unlocked for existing accounts when they log in.
  • You now specify a level parameter for items generated using !item drop and !item give commands.

Bug Fixes

  • Fixed an issue where running the server in a non-interactive container environment could cause excessive log spam and high CPU usage.
  • Fixed a server crash related to the Add G panel.
  • Fixed an issue where the sign bit of the Z axis would be applied to the X axis in Int21Vector3 encoded properties.
