MHServerEmu 1.0.2 Patch Notes

General

  • The server backend has received changes to allow it to support multiple game versions via build configurations. Official support for additional game versions will be coming in 1.1.0 after version-specific features are implemented.
  • A large scale optimization pass has been done, focusing primarily on memory management, network IO, and game data initialization. This should result in faster server startups and garbage collection (GC) pauses happening less frequently. The work on mitigating GC related lag spikes will continue in future releases.
  • The logging system has been overhauled to mirror the assertion-style "verify" semantics that the client uses.
  • Implemented a new command - !server importdb. This command can be used to import accounts and guilds from a separate SQLite database file into the current one, effectively merging them together.

Bug Fixes

  • Fixed an issue where Bonus Item Find (BIF) points were awarded for killing non-hostile entities (e.g. destructible props).
  • Fixed an issue where direct access portals (e.g. Classified Bovine Sector) could be reused to create additional instances of the destination region after disbanding a party.
  • Fixed an issue where the additional dash power charge from the Time Mastery effect of the Infinity system could be repeatedly applied to powers after a region transfer.
  • Fixed a game instance crash that would happen when using the !entity info command to inspect an entity without a power collection.
  • Fixed an issue where queued avatar power activation inputs would not be correctly cleared on power unassignment.
  • Fixed an issue where entities with invalid marker data would be spawned outside of cell bounds.
  • Fixed an issue where stale discovered entity references would be shared with party members when entering a region.
  • Fixed an issue where entities would not become resistant to crowd control status effects after being crowd controlled in some cases.
  • Fixed an issue with missile power targeting logic, which resulted in irregular behavior for some missile powers (e.g. Black Widow’s Rolling Grenades).
  • Fixed a rare full server crash that could occur when a client disconnected during the authentication process.
  • Fixed an issue where non-avatar live tuned vendor Eternity Splinter prices were not respected client-side.
  • Fixed an issue where enum fields with invalid asset references were interpreted as the default value rather than zero when parsing Calligraphy prototypes, resulting in incorrect behavior in some cases (e.g. wander AI state for Sauron and Vulture).
  • Fixed an issue where a tutorial popup was not displayed when a player equpped a Cosmic rarity item for the first time.
  • Fixed an issue where Scarlet Witch's Balance talent could trigger from hitting the boxes it summons.
  • Fixed an issue where restored Fantastic Four related achievements were not granting achievement points.
  • Fixed more typos and incorrect translations in the Russian achievement text.
